# SO-Stats

> **WIP** — early stage, structure may change.

Web app for game statistics. Node.js frontend with a Python backend layer that
fetches live data via the public Syndicate of Souls endpoints and serves it to
the UI.

## Stack

- **Frontend:** Node.js
- **Backend:** Python (data fetching / scraping of Syndicate of Souls endpoints)

## Status

In progress. Fetching and endpoint integration are the current focus; details
to be finalized as the project takes shape.
